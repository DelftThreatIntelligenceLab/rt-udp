# UDP (and TCP) Reactive Telescope

This repository contains the source code of the `rt-udp` tool used as base for the short paper _"Understanding Different Perspectives: Analyzing UDP Scanning Through Reactive Telescopes"_, to appear in the Proceedings of the 2026 ACM Internet Measurement Conference (IMC).

Documentation on the tool can be found in `USAGE.md`


## Datasets

Anonymized traffic datasets are available for download from the website of the institution responsible during runtime:
* $NL_1$ (Delft) sensor: https://delftintellab.com/projects/imc2026-udp-reactive
* $IT_1$ (Torino), $IT_2$ (Milano) and $SA_1$ (Brasil) sensors: TODO
